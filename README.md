\# Unity 2D ノベルゲームテンプレート



サークルの新入生向けに作成した、Unity初心者向けの、全画面型ノベルゲームテンプレートです。



このテンプレートでは、型月作品のような「画面全体に背景を表示し、その上に本文を重ねて表示する」形式のノベルゲームを作成します。  

会話文だけでなく、地の文を中心にした文章表示にも対応しています。



デモ用シナリオとして、芥川龍之介の『魔術』を題材にしたノベルゲームを想定しています。  

ただし、背景画像・立ち絵画像・BGM素材は配布しない前提です。  

各自で用意した画像や音楽をInspectorから設定してください。

\## ゲームの基本仕様



シナリオは「ページ」と「ブロック」の2段階で管理します。



\### ページ



ページは、背景画像やBGMが切り替わる大きな単位です。



1つのページには、以下の情報を設定できます。



\- ページ名

\- 背景画像

\- BGM

\- このページへ移動するときにフェードするか

\- ページ開始時の立ち絵状態

\- ページ内に含まれる複数の文章ブロック



\### ブロック



ブロックは、プレイヤーがボタンを押すたびに追加表示される文章の単位です。



1つのブロックには、以下の情報を設定できます。



\- 話者名

\- 本文

\- ブロック開始時に表示・差し替えする立ち絵

\- ブロック開始時に非表示にする立ち絵

\- 全立ち絵を非表示にする指定



文章は1ページ分を最初からすべて表示するのではなく、ブロックごとに少しずつ表示されます。



同じページ内では、前に表示した文章は消えません。  

次のブロックの文章が、現在の本文欄に追加されていきます。



\---



\## 操作方法



| 入力 | 動作 |

|---|---|

| Space | 次のブロックへ進む |

| Enter | 次のブロックへ進む |

| 左クリック | 次のブロックへ進む |

| ゲームパッドの決定ボタン | 次のブロックへ進む |

| Esc | シナリオの最初へ戻る |



文章が1文字ずつ表示されている途中に次へ進む入力をすると、現在のブロックの文章を一気に最後まで表示します。



文章をすべて表示した状態でもう一度入力すると、次のブロックへ進みます。



ページ内の最後のブロックまで表示した状態でさらに入力すると、次のページへ移動します。

\## 実装している機能



初期版では、以下の機能を実装しています。



\- ページ管理

\- ブロック単位の文章送り

\- 1文字ずつ表示するタイプライター風表示

\- 表示途中の文章を一気に表示する処理

\- 背景画像の切り替え

\- BGMの切り替え

\- 背景切り替え時の黒フェード

\- ページごとのフェード有無の設定

\- Left / Center / Right の3位置への立ち絵表示

\- ブロックごとの立ち絵表示・差し替え・非表示

\- ScriptableObjectによるシナリオ管理

\- Input Systemによる入力処理

\## 初期版では実装していない機能



このテンプレートでは、初心者が基本構造を理解しやすいように、以下の機能は実装していません。



\- 選択肢分岐

\- セーブ

\- ロード

\- バックログ

\- スキップ

\- オート再生

\- スチル演出

\- 細かい画像遷移演出

\- ボイス再生

\- タイトル画面

\- コンフィグ画面



これらは、基本構造を理解した後に追加する拡張要素として扱います。

\## スクリプト構成



このテンプレートは、役割ごとにスクリプトを分けています。



| スクリプト名 | 役割 |

|---|---|

| NovelScenarioData.cs | シナリオ、ページ、ブロック、立ち絵データを定義する |

| NovelManager.cs | ノベルゲーム全体の進行を管理する |

| NovelUIManager.cs | 背景画像、本文、話者名の表示を管理する |

| CharacterStandingManager.cs | 立ち絵の表示・差し替え・非表示を管理する |

| NovelAudioManager.cs | BGMの再生・停止を管理する |

| FadeController.cs | 黒フェード演出を管理する |

| NovelInputHandler.cs | キーボード、マウス、ゲームパッド入力を管理する |
